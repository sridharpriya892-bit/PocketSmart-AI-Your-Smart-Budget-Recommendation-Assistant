# Pocket Smart AI

Pocket Smart AI is an intelligent financial advisor app built with Streamlit and Google Gemini API. It helps users analyze monthly income/expenses, calculate savings, and get tailored AI-driven financial advice.

## Features
- Interactive income and expense tracking
- Automated financial health analysis
- Real-time recommendations powered by Gemini AI

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Set your API Key: `export GEMINI_API_KEY="your-api-key"`
3. Launch app: `streamlit run app.py`
